# Contributing to CoinCanvas

Thank you for your interest in the **CoinCanvas** project! We welcome all types of contributions, including bug reports, feature requests, documentation improvements, and code contributions. Please follow the guidelines below to participate in our project.

## How to Contribute

### Reporting Issues

If you encounter any bugs or have suggestions for improvements, please submit them through [GitHub Issues](https://github.com/DFY-NCSU/CoinCanvas/issues). Before submitting, search the existing issues to avoid duplicates.

**When submitting an issue, please include the following information:**

- A brief description of the issue
- Steps to reproduce the problem
- Expected and actual behavior
- Screenshots or logs, if applicable

### Submitting Feature Requests

We welcome new feature ideas. Please submit feature requests through [GitHub Issues](https://github.com/DFY-NCSU/CoinCanvas/issues) and include:

- A detailed description of the feature
- The potential use case or benefits of the feature
- Any relevant examples or references

### Contributing Code

If you’d like to contribute code, follow these steps:

1. **Fork the Repository**: Click the "Fork" button on the repository page to create a copy of the project in your GitHub account.

2. **Clone the Repository**: Clone the forked repository to your local machine.

   ```bash
   git clone https://github.com/your-username/CoinCanvas.git
   
3. **Create a Branch**: Create a new branch for your changes.
   ```bash
   git checkout -b feature/describe-your-feature
   
4. **Make Changes**: Develop and test your changes locally. Ensure that you follow the project’s coding style and best practices.
5. **Commit Changes**: Commit your changes to your branch.
   ```bash
   git add  \\your file or folder
   git commit -m "Describe your changes"
6. **Push Your Branch**: Push the branch to your GitHub repository.
   ```bash
   git push origin feature/describe-your-feature
7. **Create a Pull Request**: Open a Pull Request (PR) in the original repository, describing your changes and their purpose.
### Note
- Ensure your code is up-to-date with the latest main branch before submission.
- Run all relevant tests to ensure stability.
- Update documentation if your changes involve modifications to features.

## Coding Standards
Please follow these coding standards:

- Python: Adhere to the PEP 8 standard.
- Frontend Code: Follow the existing code style in the project.
